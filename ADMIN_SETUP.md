# Админ-панель

1. В Railway откройте сервис приложения `versad` → Variables.
2. Добавьте `ADMIN_TOKEN` со случайным длинным значением. Пример генерации локально: `openssl rand -hex 32`.
3. Рекомендуется добавить `TZ=Europe/Moscow`.
4. После деплоя откройте `https://<ваш-домен>/admin` и введите `ADMIN_TOKEN`.

Панель показывает состояние приложения, Ollama, Gemini, корпуса и checkpoint; запускает сканирование по произвольным темам; ставит автоскан на паузу; показывает последние документы и очищает сохранённую ошибку.

Все административные API требуют заголовок `X-Admin-Token`. Если `ADMIN_TOKEN` не задан, API панели возвращает 503.
